# Student Registration Form

A C# Windows Forms application that collects student details, validates the input, and displays a registration summary on the same form.

## Features

- Enter the student's name and email address.
- Select a gender using radio buttons and a course from a dropdown.
- Select multiple hobbies and choose a date of birth.
- Show a `MessageBox` when a required field is missing or the email format is invalid.
- Display all six details in a `ListBox` after successful submission.

## Built With

- C#
- Windows Forms (WinForms)
- Visual Studio 2022

## How to Run

1. Clone this repository or select **Code → Download ZIP** and extract it.
2. Open the solution file (`.sln` or `.slnx`) in Visual Studio 2022.
3. Press **F5** to run the application.
4. Fill in the form, select at least one hobby, and tick the Date of Birth checkbox.
5. Click **Submit** to see the summary below the button.
